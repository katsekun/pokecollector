## Neutral Images And Marketplace URLs

The local placeholder and end-to-end fixture are original geometric images generated by `scripts/prepare-placeholders.mjs`. They do not reproduce the official Pokemon card back or a card illustration. Both are covered by the original-work license.

Images first use TCGdex in the requested language, then optional lookups for the same card in English and French. Alternative metadata must match the card ID, set ID, number and species. The original card language remains unchanged; the image provider and reference language are preserved separately where known.

TCGplayer CDN images are an optional final provider, enabled by default. The checkbox may be disabled during the current application session and returns to the enabled default when the application is reloaded. While enabled, the application may load a product image using a numeric product ID returned by TCGdex. This does not use the authenticated TCGplayer API. No marketplace image files are bundled in the repository. Existing saved marketplace URLs remain in user data for portability and are only loaded while the option is enabled.

Permission for this CDN integration has not been established. Enabling it, attributing the provider or using the application noncommercially does not constitute permission. Confirm rights and service conditions with the provider before publicly deploying that integration. TCGplayer reference images may differ from the card's recorded language. If no image is available or its loading fails, the original neutral placeholder is used.

Replacing files in the current revision does not remove third-party artwork from earlier Git commits, screenshots or published artifacts. Repository history has not been rewritten. Review historical distribution separately before sharing a full clone or earlier release.

Image load errors also trigger verified alternative-language lookups and the optional marketplace provider, rather than immediately exhausting the chain. Recovery skips failed URLs, uses bounded detail requests and does not rewrite saved collection metadata or prices. It does not confer any additional rights in external images.
